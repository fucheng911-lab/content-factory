# Spoken Script

Use this reference when converting ideas, voice-note transcripts, interviews, or messy verbal drafts into polished spoken scripts.

## Principle

A spoken script is not an essay. It must be easy to say, easy to hear once, and easy to cut into scenes. Optimize for oral rhythm, clear progression, and visual executability.

## Extraction Pass

Before drafting, extract:

- User's own memorable phrases.
- Strong opinions or emotional turns.
- Concrete examples, names, objects, scenes, numbers, and contrasts.
- Repeated ideas that reveal the real point.
- Claims that need verification.
- Lines that sound natural and should be preserved.

Do not polish too early. First find the speaker's intent and voice.

## Script Development Flow

1. Write the core promise:
   `After watching, the viewer should believe/understand/do [specific result].`

2. Write 3-5 hook candidates:
   - Contradiction: "Most people start here, but that is the mistake."
   - Outcome: "This is how you turn a rough voice note into a finished video."
   - Problem: "Your script is not weak because the wording is bad."
   - Curiosity: "The missing step happens before you write a single scene."

3. Select one hook and build chapters:
   - Hook
   - Problem or tension
   - Core idea
   - Method, story, proof, or example
   - Takeaway
   - Optional action

4. Draft in spoken language:
   - One idea per sentence.
   - Short clauses.
   - Natural connective phrases.
   - Avoid stacked nouns and abstract slogans.
   - Keep useful repetition if it creates rhythm.

5. Read aloud and revise:
   - Cut lines that are hard to say.
   - Split sentences that need a breath.
   - Replace written phrases with spoken ones.
   - Remove claims the visuals cannot support.

## Output Files

### `spoken-script.md`

```markdown
# Spoken Script

## Core Promise

## Hook Options

1. ...
2. ...
3. ...

## Final Script

### 01 Hook
[Voiceover]

### 02 Problem
[Voiceover]
```

### `subtitle-lines.md`

```markdown
# Subtitle Lines

| Time | Voiceover | Subtitle |
|---:|---|---|
```

Subtitle rules:

- Use shorter lines than the voiceover.
- Keep mobile readability.
- Emphasize keywords, not every word.
- For Chinese, prefer compact spoken Mandarin over literal transcription.

## Quality Checklist

- The first 3 seconds establish tension, outcome, or curiosity.
- The script can be read aloud without stumbling.
- The viewer can understand the point without rereading.
- Every major line suggests a possible visual.
- Subtitles are shorter than voiceover.
- The ending lands on a takeaway or action, not a vague summary.
