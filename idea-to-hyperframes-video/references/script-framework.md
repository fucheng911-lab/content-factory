# Script Framework

Use this reference when shaping the strategic structure around a spoken video script. For oral delivery details, also read `spoken-script.md`.

## Input Normalization

Extract these fields before writing:

- Topic: what the video is about.
- Audience: who should care.
- Platform: YouTube, TikTok, Reels, Xiaohongshu, sales page, course, internal training, etc.
- Duration: target seconds or minutes.
- Intent: educate, sell, explain, announce, persuade, entertain, document, recap.
- Tone: cinematic, practical, urgent, warm, expert, luxury, playful, investigative, etc.
- Constraints: brand rules, required phrases, forbidden claims, compliance concerns.
- Raw hooks: memorable phrases from the user's own language.

If fields are missing, assume conservatively and list the assumptions at the top.

## Creative Nucleus

Write one sentence:

`This video helps [audience] understand/feel/do [outcome] by showing [specific angle].`

Then write:

- Core tension: what is confusing, painful, surprising, or desirable.
- Payoff: what the viewer gets by the end.
- Proof: what evidence, example, scene, or demonstration makes it believable.

## Chapter Structure

For most short videos, use 4-7 chapters:

1. Hook: stop the scroll with a concrete contradiction, result, or question.
2. Context: define what is happening and why now.
3. Development: explain the mechanism, story, comparison, or transformation.
4. Proof: show a detail, example, demo, quote, data point, or before/after.
5. Takeaway: compress the meaning into a memorable line.
6. Action: invite the next step only if the brief needs it.

Do not force all six if the video is very short. A 20-second piece can be Hook -> Proof -> Takeaway.

## Chapter Script Table

Use this table shape:

| Chapter | Time | Purpose | Voiceover | On-screen text | Visual beat | Asset need | Transition |
|---|---:|---|---|---|---|---|---|

Rules:

- Voiceover should sound spoken, not like an essay.
- On-screen text should be shorter than the voiceover and readable at mobile size.
- Visual beat must describe what appears on screen, not just "show image".
- Asset need should be concrete enough to search, shoot, generate, or design.
- Transition should carry meaning: reveal, contrast, zoom into detail, match cut, timeline jump, wipe by object, caption strike, etc.

## Copy Standards

- Prefer concrete nouns and verbs.
- Remove filler openings like "In today's video" unless the platform expects it.
- Avoid unexplained abstractions: "empower", "innovative", "premium", "solutions".
- Keep one idea per sentence for short-form video.
- Use a repeated phrase only if it creates rhythm.
- For Chinese copy, write natural spoken Mandarin first, then tighten subtitles.

## Spoken vs. Subtitle

Keep separate versions:

- Voiceover: natural spoken line, allowed to be slightly longer.
- Subtitle: compressed screen text, designed for reading at speed.
- On-screen emphasis: even shorter keywords or labels.

Do not use the full voiceover as the only subtitle layer unless the user explicitly needs full captions.

## Verification Notes

When the script mentions facts, dates, prices, laws, named people, current products, recent events, or statistics, verify with reliable sources before finalizing. If verification is not possible in the current turn, mark the line as `[needs verification]`.
